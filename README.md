# 知安 · AI 反诈守护

> 第九届传智杯 AI Web 网页开发挑战赛参赛作品
>
> 在线体验：**https://zhian-plum.vercel.app**（使用免费大模型，高峰期繁忙时会自动改用规则引擎，结果照常给出）

**念安**是一位原创的 AI 守护姐姐。可疑的短信、聊天截图、陌生链接和电话号码，都可以交给她。她会一步步检索骗局知识库、检查链接和号码，给出带依据的风险报告，并告诉你接下来该怎么做。

## 功能

| 页面 | 状态 | 说明 |
| --- | --- | --- |
| 首页 | ✅ | 角色主视觉、分人群高发骗局、工作流程 |
| 检测台 | ✅ | 文字 / 截图 / 链接 / 号码检测，Agent 思考过程实时可视化，风险报告 |
| 聊天护航 | ✅ | 和可疑的人聊天时逐条贴进来，实时风险曲线、骗局阶段、话术高亮、下一步预测、回复建议，发送前拦截验证码和转账 |
| 演练场 | ✅ | AI 扮演骗子和你聊天，识破或上当后给出五维防骗力评分、雷达图和逐句复盘 |
| 骗局图鉴 | ✅ | 16 类骗局知识库，可按人群筛选、搜索 |
| 我的档案 | ✅ | 演练成绩、防骗力雷达图、得分趋势、检测记录（仅保存在本地浏览器） |
| 紧急求助 | ✅ | 被骗后的处理步骤 |

## 技术架构

- **前端**：Next.js 16（App Router）+ React 19 + TypeScript + Tailwind CSS 4 + Motion
- **AI**：Vercel AI SDK 7，OpenAI 兼容接口（默认智谱免费模型 GLM-4.7-Flash / GLM-4.6V-Flash，可换任意兼容服务）
- **检测 Agent**（`src/lib/agent.ts`）
  - 大模型自主规划，调用 4 个工具（Function Calling）：
    `search_scam_knowledge` 骗局知识库检索、`analyze_url` 链接检查（含 RDAP 域名注册时间查询）、
    `analyze_phone` 号码检查、`submit_report` 提交结构化报告
  - 截图先由视觉模型转写，再交给 Agent 分析（多模态）
  - 报告与规则引擎交叉校验，模型漏判时取更谨慎的结果；模型未提交报告时由规则引擎兜底
  - 待检测内容以标签包裹并声明为数据，防御提示词注入
- **聊天护航**（`src/lib/guard.ts`、`src/lib/guard-agent.ts`）
  - 规则引擎在浏览器里即时计算：逐条累计风险曲线、识别 10 类话术（自称身份、抛出诱饵、恐吓施压、要求保密、索要验证码等）、判断骗局走到了「接近 → 诱饵 → 施压 → 要钱」哪一步
  - 用文本相似度把对方的话对齐到知识库里同类骗局的剧本，预测对方的下一句
  - 大模型检索知识库后提交结构化研判（风险、阶段、下一步、回复建议），再流式说出点评；研判与规则引擎交叉校验，取更谨慎的结果
  - 用户的回复发出前先过一遍确定性检查，验证码、卡号、身份证号、答应转账、共享屏幕会被当场拦下
  - 聊天截图由视觉模型按左右气泡转写成双方对话（多模态）
- **演练场**（`src/lib/drill.ts`、`src/lib/drill-agent.ts`）
  - 大模型按剧本阶段扮演骗子，提示词限定只用剧本内套路，输出再经过安全过滤（屏蔽链接和长数字）
  - 陷阱检测、应对行为分析、五维评分都是确定性规则，评分在服务端重算，不信任前端
  - 复盘时用文本相似度把骗子的每句话匹配到剧本的逐句套路说明；念安点评由大模型生成，失败时用模板兜底
- **知识库检索**（`src/lib/analyze.ts`）：关键词命中 + 字符二元组余弦相似度的混合检索
- **事件流**：`/api/detect`、`/api/guard` 以 NDJSON 逐行推送 Agent 每一步，前端实时渲染
- **演示模式**：未配置 API Key 时，用同一套工具 + 规则引擎跑完整流程，页面随时可演示

```
src/
├─ app/                 页面与接口（api/detect 检测、api/guard 聊天护航、api/drill 演练）
├─ components/          页面组件（detect/ 检测台、guard/ 聊天护航、drill/ 演练场、home/ 首页）
├─ data/                骗局知识库、演练剧本、护航演示对话
└─ lib/                 Agent、检测工具、事件协议、本地记录
```

## 运行

```bash
npm install
cp .env.example .env.local   # 填入 AI_API_KEY（不填则为演示模式）
npm run dev
```

打开 http://localhost:3000

### 环境变量

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `AI_API_KEY` | 大模型 API Key，不填则为演示模式 | 空 |
| `AI_BASE_URL` | OpenAI 兼容接口地址 | `https://open.bigmodel.cn/api/paas/v4` |
| `AI_MODEL` | 文本模型，需支持工具调用 | `glm-4.7-flash` |
| `AI_VISION_MODEL` | 视觉模型，用于识别截图 | `glm-4.6v-flash` |
| `AI_FALLBACK_MODELS` | 主模型繁忙时换用的备用模型（逗号分隔），都失败时由规则引擎兜底 | `glm-4.6v-flash` |
| `RATE_LIMIT_DETECT_PER_MIN` / `_GUARD_` / `_DRILL_` | 每个 IP 每分钟的请求上限，超出时提示稍后再试 | `8` / `20` / `30` |
| `AI_DAILY_LIMIT_PER_IP` / `AI_DAILY_LIMIT_TOTAL` | 每天调用大模型的上限（单个 IP / 全站），用完自动改用规则引擎 | `100` / `3000` |
